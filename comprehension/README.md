Comprehensions are a concise way to create the following using a single line of code. 
 - lists,
 - sets,
 - dictionaries
 - generators 

 ## Where used?
 - Filter an item
 - Transform item
 - Create a new collection 
 - Flatten nested structure 

 ## how it differs from loop?
 - Cleaner code 
 - Faster execution, and less memory 

 ## Types of comprehension 
 - List -> [expression for item in itererable if condition ]
 - Set (return unique items in a list) -> {expression for item in itererable if condition } 
 - Dictionary -> as same as Set and it will return the data in key value pairs 
 - Generator -> same as list but it won't save in memory rather stream the data -> (expression for item in itererable if condition)
